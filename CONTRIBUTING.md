# Contributing to NOTERA

Thank you for your interest in improving NOTERA.

## Getting started

1. Fork the repository and create a focused branch.
2. Follow the setup instructions in `README.md`.
3. Keep changes small and scoped to one issue when possible.
4. Add or update tests for behavior changes.
5. Run the relevant backend/frontend tests before opening a pull request.

## Issues

Use GitHub Issues for reproducible bugs, feature proposals, documentation gaps, and provider/model compatibility reports. Include environment details and reproduction steps where applicable. Do not include API keys, private documents, personal data, or proprietary material.

## Pull requests

Describe the problem, the approach, how you verified the change, and any compatibility implications. Preserve existing behavior unless the change intentionally modifies it and is documented.

## AI-assisted contributions

AI-assisted contributions are welcome, but contributors remain responsible for reviewing generated changes, verifying tests, respecting licenses, and ensuring that no secrets or private data are submitted.

## Security

Please do not disclose security vulnerabilities in public issues. Follow `SECURITY.md` instead.
