# Security Policy

## Supported versions

Security fixes are applied to the latest development version and current releases of NOTERA where practical.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the maintainer through GitHub's private vulnerability reporting feature when available. If private reporting is not available, contact the maintainer through the contact method listed on the maintainer's GitHub profile and avoid publishing exploit details until a fix is available.

Please include reproduction steps, affected components, expected impact, and any suggested mitigation.

## Sensitive data

NOTERA processes user-provided media and documents. Never commit real API keys, credentials, private documents, personal data, model credentials, or production configuration to this repository. Use `.env` locally and keep only safe placeholders in `.env.example`.
